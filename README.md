# AccessiblePortfolio
A multi-page personal portfolio website built with semantic HTML5, accessibility best practices, ARIA attributes, SEO-friendly metadata, and a keyboard-accessible contact form.


## 📌 Project Overview

This project is a multi-page personal portfolio website developed using modern semantic HTML5 standards and accessibility best practices.

The website is designed to provide a clear structure for screen readers, keyboard users, and search engines.

## ✨ Features

* Semantic HTML5 structure
* Accessible navigation
* ARIA labels and attributes
* Skip-to-main-content link
* Keyboard-friendly navigation
* Accessible contact form
* Proper form labels and field grouping
* SEO-friendly meta tags
* Responsive design
* Descriptive image alternative text
* Clear heading hierarchy
* Visible keyboard focus indicators

## 📄 Pages

* **Home** – Introduction and portfolio highlights
* **About** – Education, skills and certifications
* **Projects** – Academic and technical projects
* **Contact** – Accessible contact form

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## ♿ Accessibility

The website follows accessibility-oriented practices including:

* Semantic elements such as `header`, `nav`, `main`, `section`, `article` and `footer`
* Proper heading hierarchy
* Labels associated with form controls
* ARIA attributes where appropriate
* Keyboard navigation support
* Skip navigation link
* Alternative text for images
* Visible focus states

## 🔍 SEO

Each page includes:

* Descriptive page titles
* Meta descriptions
* Viewport metadata
* Author metadata
* Semantic headings
* Meaningful page structure
